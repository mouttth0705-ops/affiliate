# Affiliate（推广计划）界面原型

RoxyBrowser 客户端内 **推广 / 邀请** 概览页的单文件静态原型，用于产品与视觉对齐：侧栏工作台、账户概览、推广链接与邀请码、返利说明、推广宣传图嵌入、达人排行榜、商务经理引导等。

## 使用方式

无需安装依赖，直接用浏览器打开根目录下的 `index.html` 即可预览。

建议使用本地静态服务（避免部分环境下 `file://` 与剪贴板 API 限制）：

```bash
# 示例：Python 3
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 功能说明（页面内）

- **工作台外壳**：窗口标题栏、左侧导航、顶栏（空间 / 通知 / 用户）、促销横幅与 Tab。
- **账户概览**：可提现余额、点击与邀请相关统计、审核中与奖励等。
- **推广链接 & 邀请码**：只读展示链接与邀请码、复制与 Toast；内置 `(i)` 气泡说明。
- **返利说明**：您将获得 / 他们得到 比例卡片区。
- **商务经理**：返利文案下方的引导行，内联「添加商务经理」链接触发二维码弹窗（二维码图可在 HTML 中通过 `data-qr-src` 或脚本内占位地址替换）。
- **推广宣传图**：尺寸切换、预览占位、HTML 嵌入代码与一键复制（嵌入链接域名与邀请码与页面字段联动）。
- **推广达人排行榜**：表格样式 Top 10 示例数据。

## 可配置项（开发对接时）

在 `index.html` 中可集中替换或接入接口：

- 推广主域与路径：如 `roxybrowser.cn`、`/invite/{code}`。
- 邀请码示例、统计与排行数据（当前为展示用静态值）。
- 横幅 CDN：`BANNER_CDN_BASE`（脚本内）与二维码 `data-qr-src`。
